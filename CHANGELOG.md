# Changelog

All notable changes to Papora are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Full open source community kit: CONTRIBUTING.md, CODE_OF_CONDUCT.md,
  SECURITY.md, issue templates, and a pull request template
- GitHub Actions CI running lint and build on every push and pull request

### Changed

- Rewrote every piece of copy on the landing page and across the app, from the
  hero and how-it-works sections to sidebar labels, editor section titles, and
  page metadata
- Renamed every file and component into a coherent structure: `home` became
  `landing`, `ui` became `shell`, `common` became `shared`, and all invoice,
  receipt, PDF, and utility modules got descriptive names
- Refreshed the phone demo on the landing page with new sample content and
  step captions
- README rewritten as a full project guide

### Fixed

- Default invoice terms section title read "Terms & Condition" instead of
  "Terms and conditions"
- Double space in the sidebar bug report label
